# Code Review Skill

When asked to review code:

1. Read the changed files fully before commenting.
2. Check correctness first: edge cases, error handling, off-by-one errors.
3. Then check maintainability: naming, duplication, module boundaries.
4. Verify claims by running the project's tests when available.

Report findings as a numbered list ordered by severity.
