# 升级判断规则

- **金额**：涉及金额 > 200 元 → 升级 L2（主管）。
- **身份**：VIP 或企业客户且诉求未获满足 → 升级 L1（组长）。
- **风险**：涉及法律、媒体、支付安全、数据泄露 → 一律升级 L2。

## 流程

1. 先 `classify_ticket` 落盘判定（分类/优先级/意图）。
2. 再 `escalate_ticket`，`level` 取 1 或 2，理由中引用命中的知识库文章 id。
3. 升级不等于停止分流：仍要给出建议队列，便于升级处理人排期。
