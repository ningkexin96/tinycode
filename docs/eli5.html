🐹 TinyCode

一个住在你终端里的 AI 编程小助手 —— 它是怎么工作的？

全程只用图画 + 大白话，5 分钟看懂。

1️⃣ TinyCode 是什么？

你用中文说想要什么，它自己动手改代码。

它不是聊天机器人 —— 它有手（工具），能真的读文件、改文件、跑命令。

2️⃣ 核心：一个不停转的圈圈 🔄

AI 大脑不会直接碰你的电脑，每一步都靠这个循环。

这个圈圈叫 Agent Loop（代理循环），是所有 AI 编程助手的心脏。TinyCode 的循环由 Pi 库驱动。

3️⃣ 它的七件工具 🧰

大脑很聪明，但没有手什么都做不了。工具就是它的手。

👀 read 看文件 ✏️ write 新建文件 🔧 edit 精准改几行 ⚡ bash 跑命令 🔍 grep 搜内容 🗺️ find 找文件名 📂 ls 看目录

每个工具都有使用说明书（参数格式）。AI 看说明书点菜，TinyCode 负责上菜。

4️⃣ 安全带：红绿灯规则 🚦

AI 不是每件事都能偷偷干，危险的事必须先问你。

改你项目外的东西？永远不行。它还认得“绕路的小抄”（符号链接），骗不过去。

5️⃣ 记性：一本只加页的日记本 📓

聊过的每一句、干过的每一件事都记下来，关掉程序也不丢。

所以 tinycode --continue 能接上昨天的对话。每段对话一个独立本子，不同项目不串台。

6️⃣ 行李箱：AI 的记性是有限的 🧳

大脑一次只能装那么多字。装不下怎么办？两招。

重要的事永远保留：你最新的要求、最近改的文件、最近出的错。

7️⃣ 它还有三个帮手 🤝

自己不够用时，会请外援。

📖 技能 Skills
项目里的说明书，需要时才翻 🔌 MCP 外挂
接上外面的工具，比如查网页 👥 子代理 Sub-Agent
派小弟去翻代码，只带结论回来

8️⃣ 一句大实话 ⚠️

TinyCode 的红绿灯是礼貌的门卫，不是监狱围墙。

它能拦住不小心，拦不住故意使坏。
让 AI 跑来路不明的任务时，请关在容器/虚拟机里。
